# Changelog

Все заметные изменения проекта документируются в этом файле.

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [семантическое (SemVer)](https://semver.org/lang/ru/).

## Как версионируется проект

- Все заметные изменения записываются в `[Unreleased]` по ходу разработки.
  Секция превращается в релиз `[X.Y.Z] - дата` и создаётся тег `vX.Y.Z`
  только по явной команде владельца.
- До версии 1.0 минорная версия может содержать новые функции и несовместимые
  изменения, патч — исправления без изменения поведения.
- С версии 1.0 минорная версия добавляет обратно совместимые функции, патч
  содержит исправления, а мажорная версия — несовместимые изменения.

## [0.1.0] - 2026-11-17

### Добавлено

- Сервис `nftguard` для блокировки входящих IPv4- и IPv6-адресов сканеров и
  сетей из списков C24Be и AntiScanner на уровне nftables; опциональная
  блокировка исходящих соединений к сетям VK, MAX и OK.
- Исключения IPv4 и IPv6, пропуск loopback и установленных соединений до
  проверки блок-листа. Правила размещаются в отдельной таблице
  `inet nftguard` и не изменяют чужие таблицы.
- Загрузка списков при запуске и по ежедневному расписанию с настройками
  часового пояса, таймаута и повторов; проверка размера и содержимого списков
  перед применением. При ошибке обязательных источников сохраняются текущие
  правила, при ошибке AntiScanner обновление продолжается с C24Be.
- Атомарное применение и сохранение правил, восстановление свежего состояния
  при запуске, попытка отката при ошибке проверки применённой таблицы, журнал
  событий и healthcheck. Пробный режим `DRY_RUN` по умолчанию не меняет правила.
- Публикация multi-arch образа в GHCR по релизному тегу после тестов;
  установка готового образа без сборки и возможность закрепить версию.
- Docker-образ и конфигурация Docker Compose, пример настроек `.env.example`,
  интерактивные установщик и удаление сервиса с подтверждением.
- Задержка применения и восстановления правил после загрузки Linux: параметр
  `BOOT_DELAY_SECONDS` (по умолчанию 120 секунд) отсчитывается от запуска
  системы, а не контейнера; `0` отключает задержку.
- Изолированный Docker-набор модульных и функциональных тестов, отчёты
  покрытия с порогом 95% и запуск проверок в GitHub Actions.
- Инструкции для работы с проектом в `AGENTS.md`.
- Пользовательская документация по установке, настройке, эксплуатации и
  тестированию; лицензия проекта MIT и сведения об источниках списков.
